06核心代码
分析全流程的关键 Python 代码段。
数据清洗与聚合
# 数据清洗 df = df[df['capacity'] >= 0] df = df[df['ticket_use'] >= 0] df = df[df['occu_perc'] <= 100] # 按影院聚合 cinema_df = df.groupby('cinema_code').agg( total_sales=('total_sales', 'sum'), tickets_sold=('tickets_sold', 'sum'), avg_occu=('occu_perc', 'mean'), avg_price=('ticket_price', 'mean'), avg_capacity=('capacity', 'mean'), show_count=('film_code', 'count'), film_count=('film_code', 'nunique') ).reset_index()
K-means 聚类
from sklearn.preprocessing import StandardScaler from sklearn.cluster import KMeans features = ['total_sales', 'tickets_sold', 'avg_occu', 'avg_price', 'avg_capacity', 'show_count', 'film_count'] scaler = StandardScaler() X_scaled = scaler.fit_transform(cinema_df[features]) inertias = [] for k in range(2, 11): km = KMeans(n_clusters=k, random_state=42) km.fit(X_scaled) inertias.append(km.inertia_) kmeans = KMeans(n_clusters=4, random_state=42) cinema_df['cluster'] = kmeans.fit_predict(X_scaled)
综合评分与推荐
from sklearn.preprocessing import MinMaxScaler mm = MinMaxScaler() score_cols = ['total_sales', 'avg_occu', 'show_count', 'film_count'] score_data = mm.fit_transform(cinema_df[score_cols]) weights = [0.3, 0.3, 0.2, 0.2] cinema_df['score'] = score_data @ weights top10 = cinema_df.nlargest(10, 'score') print(top10[['cinema_code', 'score', 'cluster_name']])
07分析报告
代码编写过程中遇到的问题、模型选择原因、结果分析与学生数据标识。
一、遇到的问题与解决
1. 中文编码问题
Windows 下 Python 输出中文出现乱码。解决：脚本开头添加 sys.stdout.reconfigure(encoding='utf-8')，设置 matplotlib 中文字体为 SimHei。

2. 数据异常值
原始数据中存在 capacity 为负数（3 条）、ticket_use 为负数（4 条）、上座率超过 100%（7 条）的异常记录，通过条件过滤移除。

3. 特征量纲差异
总票房（亿元级）和上座率（百分比级）量纲差异巨大，使用 StandardScaler 标准化解决。

4. 聚类数选择
通过肘部法分析，K=4 处拐点明显，且业务含义清晰。
二、模型选择原因
选择 K-means：
1. 数据量适中（239 家影院），K-means 效率高
2. 特征分布相对集中，适合基于距离的聚类
3. 结果易于解释

不选其他方法：
- DBSCAN：密度差异大，难以确定 ε 参数
- 层次聚类：计算量偏大
- 高斯混合模型：数据不一定符合高斯分布假设
三、结果分析
聚类发现：239 家影院分为 4 类——
1. 顶级影院（5 家）：仅占 2.1%，首映首选。
2. 热门影院（42 家）：各项指标中上，适合备选。
3. 中等影院（40 家）：上座率偏低（6.6%）。
4. 普通影院（152 家）：占 63.6%，单体贡献小。

首推：影院 #448，综合评分 0.847。
